# 02. Read the browsers from the browserslist config

**Date**: 2026-11-15

**Independent facts**:

- SWC, Webpack and `postcss-preset-env` read the browsers in the same order: the
  `BROWSERSLIST` variable, the `BROWSERSLIST_CONFIG` file, then the nearest
  `.browserslistrc` or `browserslist` field of `package.json`, from a given
  folder up
- Without any of them, SWC keeps the syntax as written, Webpack stops with an
  error, and `postcss-preset-env` uses the defaults of browserslist

**Problem**:

- VBlocks gave SWC and Webpack the query of its default `.swcrc`,
  `> 0.25%, not dead`
- VBlocks gave `postcss-preset-env` no query, so it compiled the CSS for the
  defaults of browserslist, `> 0.5%, last 2 versions, Firefox ESR, not dead`
- An app that picked other browsers had to set them in two places: `env.targets`
  of `.swcrc`, and a browserslist config for `postcss-preset-env`

**Solution**:

- The app's browserslist config sets the browsers of SWC, Webpack and
  `postcss-preset-env`. Each tool reads it from the app folder up
- Without one, `serve` and `build` give the three tools the VBlocks default,
  `> 0.25%, not dead`. The old default `.swcrc` set the same query
- `vblocks eject browserslist` prints the default, to copy into the app

**Acknowledgments**:

- An app's `.swcrc` that sets `env.targets` overrides the browserslist config,
  for SWC only
- Run outside VBlocks, eg. by `npx webpack`, the three tools get no default
  browserslist config
